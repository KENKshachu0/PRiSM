# 商户工作台的开店指引

店长第一次进入工作台时，看到的是按日常运营排列的页签：在店、玩家、设备、计费……这些页面之间的依赖关系，界面上看不出来。比如新建的计费规则要在设置里选中才会用于入场，门锁要先连接店铺的 TTLock 账号。「开店指引」页签把接入顺序和这些依赖摆到一处，并从现有接口推算每一步是否已经完成。

实现见 `packages/prism-web/src/ui/merchant/ShopGuide.tsx`（页面与加载）和 `setup-guide.ts`（纯推导，测试在 `setup-guide.test.ts`）。没有新增后端接口。

## 何时出现、默认落点

- 只对店长（owner）显示。员工看不到，也不会额外请求只有店长才能读的接口。
- 有未完成步骤时，「开店指引」排在页签最前，`/merchant/:shop` 默认跳到 `/merchant/:shop/guide`。
- 全部完成后，页签自动消失，`/merchant/:shop` 改为默认进入日常页面：计费店铺进「在店」，只用设备的店铺进「设备」。之后可从设置页标题右侧的「开店指引」链接重新打开；完成后页面显示「基础接入已完成」。
- 新建店铺的向导结束后直接进入指引。
- 计费店铺的页签顺序为：在店、玩家、设备、计费、资产、记录、设置。

## 页面结构

1. **玩家在店里怎么用**：计费店铺为 扫码 → 入场 → 用设备 → 结账 四步；只用设备的店铺为 扫码 → 用设备 两步。下方用一句话说明每个页签的用途。
2. **接入步骤**：有序清单。每一步包括：一句界面上看不出来的说明；未完成时用红字写明后果；一个直达对应位置的按钮。第一个未完成的步骤用主按钮高亮。
3. **按需配置**：接入 Bot、邀请店员、优惠礼物与兑换码（只用设备的店铺换成「启用入场计费」）、到店位置校验、从 prism-neo 迁移。每张卡片链接到对应的设置分组或页面，部分卡片显示当前状态，例如「已连接」「成员：2」。

## 步骤与完成判定

| 步骤 | 何时出现 | 完成条件 | 数据来源 |
| --- | --- | --- | --- |
| 设定收费标准 | 计费店铺 | `billingConfiguration.ready` | `GET /shops/:code/settings` |
| 决定玩家如何进店 | 计费店铺；或任一设备有门锁、麻将能力 | 不要求绑定平台身份；或有有效的 integration 令牌且 `lastUsedAt` 非空 | `settings`、`staff/api-tokens` |
| 添加设备并配置能力 | 总是 | 至少一台设备，且没有未配置能力的设备 | `GET /merchant/machines` |
| 连接 TTLock 账号 | 有设备启用了开门密码 | `ttLockConnection` 有 `clientId`、`clientSecret`，以及 `accessToken` 或 `appAccount` | `staff/settings` |
| 决定玩家怎么付钱 | 计费店铺 | 开启了前台收银；或设置了新玩家礼物；或已有玩家余额大于 0 | `settings`、`staff/settings`、`staff/players` |
| 贴好二维码，自己试一次 | 总是 | 计费店铺已有玩家档案；或店长勾选「我已试过」（按店铺存于 `localStorage` 的 `prism.setup.trial.<shopCode>`） | `staff/players` |

「设定收费标准」未完成时区分两种原因：余额资产缺失时，按钮链接到资产页；入场规则未选或已失效时，按钮链接到「设置 → 营业与计费」。

身份判定和服务端关口一致。计费店铺的所有设备，以及任何店铺的门锁和麻将桌，扫码时都要求玩家是本店玩家（见 `device-session.ts` 的 `gate`）。新店默认「要求绑定平台身份」且不自动建档，没有 Bot 时新玩家会卡在绑定这一步。指引在这种情况下标红提示。

## 玩家身份的三种策略

「设置 → 玩家与身份」和指引共用同一个三选一控件（`IdentityPolicyPicker.tsx`），对应店铺的两个开关：

| 策略 | `identityBindingRequired` | `autoRegister` |
| --- | --- | --- |
| 登录网页账号即可 | `false` | 不变 |
| 绑定 Bot 身份，自动建档 | `true` | `true` |
| 绑定 Bot 身份，只认已有档案 | `true` | `false` |

关闭绑定要求时，自动建档开关不影响入场，因此界面上统一显示为第一种策略。新建店铺向导不再询问自动建档，统一在指引里决定（创建请求仍发送 `autoRegister: false`）。

## 刷新

状态在每次打开指引时重新读取，在 `prism-shop-settings` 事件后也会刷新，并按店铺缓存，切换页签时不会闪出「加载中」。任何一项可选数据读取失败，都只会让对应步骤按「未完成」显示，不阻塞工作台。
